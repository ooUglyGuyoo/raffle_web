## 🎯 抽奖规则(现场大屏同步展示)

1. 本次抽奖共 **三轮**,全程由电脑系统随机抽取,公平公正;
2. 抽奖编号为**票面号**:观众 `No. 1000001 – 1000800`、Crew `No. 6000001 – 6000100`、VIP `No. 8000001 – 8000050`,混合抽取;
3. 每个号码**全场仅可中奖一次**,已中奖号码自动移出,不再参与后续抽取;
4. 中奖编号以**现场大屏幕公布为准**;
5. 中奖者请核对自己门票上的编号,晚会结束后**凭门票到签到处领取奖品**。

## 🔒 公平性说明(如何打消疑虑)

- **范围公开**:晚会开场第一屏即展示全部抽奖号码范围,现场观众可直接核对;
- **无法预测**:所有号码混合成单一号码池,使用浏览器内置的**加密级安全随机数**(Web Crypto `crypto.getRandomValues`)洗牌后按顺序抽取——任何人(包括工作人员)都无法预知或操纵结果;
- **不会重复中奖**:抽中的号码立即从池中移除,同一号码全场不可能中两次;
- **结果当场公开**:每轮中奖号码由大屏幕现场逐轮公布,并保留完整记录;
- **可导出核对**:活动结束后可一键导出中奖名单(`.txt` / `.csv`),供签到处逐票核对;
- **纯前端、不联网**:页面为纯前端程序,不向任何服务器传输数据,结果不存在被远程篡改的可能。

## 🛠 工作人员操作指南

1. **打开页面**即进入号码范围页(无需密码);
2. **开场前检查号码范围页**:如需调整,点"编辑"只修改各分类的起始/结束(后四位),保存后号码池自动重新洗牌;
3. **推进流程**:全程按 `空格` / `回车`(或屏幕上的"开始抽奖"按钮):
   号码范围页 → 规则页 → 第一轮(奖品总览 → 抽奖) → 第二轮 → 第三轮 → 谢幕页;
4. **防误触**:每轮结果出现后 2 秒内按键无效;若误操作可返回,谢幕页可导出中奖名单;
5. **彩排/试抽后**:在号码范围页点"重置本场记录"即可清空重来;
6. **现场断网**:直接双击本地保存的 `index.html` 即可运行,功能完全一致。

## 💻 技术说明与修改

- `index.html` 为单文件:样式、脚本、奖品图与品牌 Logo 全部内嵌(base64),无任何外部依赖;
- 修改奖品/轮次:编辑 `index.html` 中 `ROUNDS` 常量;
- 修改号码范围:页面内直接编辑(见上文),或改 `DEFAULT_RANGES`;
- 更换奖品图/Logo:`src/` 内为原始素材,运行 `src/embed_images.py` 即可重新生成内嵌版本。

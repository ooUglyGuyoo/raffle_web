## 抽奖规则

1. 本次抽奖共三轮，全程由电脑系统随机抽取，公平公正；
2. 抽奖编号为票面号：观众 No. 1000001–1000800、Crew No. 6000001–6000100、VIP No. 8000001–8000050，混合抽取；
3. 每个号码全场仅可中奖一次，已中奖号码自动移出，不再参与后续抽取；
4. 中奖编号以现场大屏幕公布为准；
5. 中奖者请核对自己门票上的编号，晚会结束后凭门票到签到处领取奖品。

## 公平性说明

- 抽奖开始前，大屏幕会公示全部抽奖号码范围，现场观众可直接核对；
- 所有号码混合成一个号码池，由电脑以加密级随机数洗牌后抽取——任何人（包括工作人员）都无法预知或操纵结果；
- 抽中的号码立即从池中移出，同一号码全场不可能中两次；
- 每轮结果当场在大屏幕公布，全程留有记录，活动结束后可导出完整中奖名单供核对；
- 本页面为纯前端程序：不联网、不传输任何数据，结果不存在被远程篡改的可能。

## 现场流程

- 开场前，大屏幕公示号码范围；
- 晚会进行中，由工作人员操作（按 空格 / 回车 推进）：号码范围 → 抽奖规则 → 第一轮 → 第二轮 → 第三轮 → 公布全部中奖名单；
- 每轮所有奖项一次摇出，中奖号码当场定格显示在大屏；
- 谢幕页公布三轮全部中奖名单，现场可导出名单文件供签到处核对。

## 技术说明

- 页面为单文件网页，样式、脚本、奖品图与品牌 Logo 全部内嵌，断网也能离线运行；
- 抽奖全程在本地电脑完成，不依赖服务器、不上传任何数据；
- 奖品、号码范围等数据均可在开场前由工作人员在页面内调整。

## 领奖方式

中奖者请核对自己门票上的编号，晚会结束后凭门票到签到处领取奖品。
